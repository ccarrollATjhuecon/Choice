# JHU Economics 180.603 - Advanced Macroeconomics I

## Intertemporal Choice

**The lecture notes are the book** *A Gentle Introduction to Intertemporal Choice*:
<https://jhu-econ.github.io/intertemporal-choice/>. **The syllabus** is at
<https://ccarrollatjhuecon.github.io/Choice-Syllabus-Latest/>.

This repo holds past exams with answer keys, and a few frozen LaTeX handouts
(see `LectureNotes/README.md`).

You will find problem sets, exams, and other ephemera in the repo `ccarrollATjhuecon/Choice-YYYY`
where `YYYY` is the year in which you are taking the course.

For example, if you are taking the course in 2026, go to

`ccarrollATjhuecon/Choice-2026`
